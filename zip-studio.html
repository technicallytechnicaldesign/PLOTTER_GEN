Dust and noise are what compression hates: watch the runs pile up, the tree spread and the tape grow past the picture it came from. The colour pen draws the code itself: the holes in the tape, the 0s and 1s on the branches and the marks on the zipper teeth. Split export saves one SVG per pen, numbered in plotting order, all with the same four corner ticks so Design Space sizes them identically.

computing

Each row of the picture is read left to right as alternating runs, white first (a row that starts black opens with a white run of 0). The runs are counted, and a Huffman tree gives the common lengths short codes and the rare ones long codes; it is drawn as the canonical tree that is actually written, 0 to the left and 1 to the right. The tape starts with a code book (the grid size, then every run length's code length) and the coded runs follow from the DATA mark, padded to a whole byte. The zipper teeth carry the opening bits of the same tape, a mark for each 1, alternating sides, though the slider and pull hide a few. In Design Space: three layers to Pen, black 0.4 for outlines, text and the tree, black 0.3 (or grey) for the hatching, the colour pen last, Attach, Make.

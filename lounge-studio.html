Lounge studio

A living room drawn as a CAD plan: walls in poché, furniture as library blocks, the cats on a layer of their own, lounging wherever they please, with the sofa marked OCCUPIED in a revision cloud. Plot the cats in a colour pen to make the layer show. Day 20 of Inktober, "lounge".

Split export saves one SVG per pen in plotting order: the thin pen, the black line, then the colour pen last so the cats sit on top of everything. Each file carries four corner ticks so they all land in the same place.

computing

How it is made: the room is laid out in centimetres and drawn at the largest standard scale that fits the sheet, so the scale in the title block is true. Every piece of furniture is a block with an outline that hides what is under it, so the sofa covers the rug and a cat covers the sofa. Each cat is a few overlapping shapes (body, head, ears, paws, tail) merged into one outline, with the tail laid over the top where it wraps round. Seen from above, a curled cat is a donut and a stretched one is longer than the sofa, which is the joke the dimension makes.

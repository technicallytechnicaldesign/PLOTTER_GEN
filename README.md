# PLOTTER_GEN

Pen-plotter generators for the Cricut Explore 5, live at https://technicallytechnicaldesign.github.io/PLOTTER_GEN/

Every page is a self-contained HTML file that exports millimetre-exact SVGs, one per pen, for Design Space (Pen, Attach, Make).

- **Hide**: the purloined plot studio and the cipher garden turn a message into a drawing; the overlay studio splits one across two sheets.
- **Read**: the plot decoder reads a hidden message back from a photo or the phone camera.
- **Gears**: four gear studios built from a parametric OpenSCAD spur gear.

src/ holds the sources the pages are built from. They are developed in a private workspace and mirrored here by publish-site.mjs, so edit there, not here. The hidden-message encoders come from [Unravel the Purloined](https://github.com/technicallytechnicaldesign/unravel-the-purloined). Classical ciphers are historical puzzles, not modern security.
